# چت ساده با WebSocket

دو پروژه‌ی کوچک برای یادگیری ارسال و دریافت پیام real-time:

- `backend` — NestJS + WebSocket خام (`@nestjs/websockets` و `@nestjs/platform-ws`)
- `frontend` — Next.js با WebSocket مرورگر (`new WebSocket(...)`)

پیام‌ها ذخیره نمی‌شوند. فقط بین کاربرهایی که همین الان وصل هستند رد و بدل می‌شوند.

## اجرا

ترمینال ۱ — بک‌اند:

```bash
cd backend
npm install
npm start
```

ترمینال ۲ — فرانت:

```bash
cd frontend
npm install
npm run dev
```

بعد مرورگر را روی [http://localhost:3000](http://localhost:3000) باز کنید. برای دیدن broadcast، همان صفحه را در دو تب باز کنید.

ابتدا یک نام ساده وارد می‌کنید (لاگین واقعی نیست). بعد از ورود، وضعیت اتصال، نام فرستنده و ساعت هر پیام نشان داده می‌شود.

## جریان کار

1. بعد از وارد کردن نام، فرانت به `ws://localhost:3001` وصل می‌شود.
2. با زدن ارسال، یک JSON شامل نام، متن و ساعت فرستاده می‌شود.
3. بک‌اند همان رشته را برای همه‌ی کلاینت‌های متصل پخش می‌کند و چیزی ذخیره نمی‌کند.
4. هر کلاینت JSON را می‌خواند، پیام را نشان می‌دهد و به آخرین پیام اسکرول می‌کند.
